# Technical references

- Check COM origins, MZ entry registers, relocation tables, image lengths and overlay handling against the original Microsoft Press description and the DJGPP format tables. [MS-DOS Encyclopedia, section II](https://msarchive.pcjs.org/mspl13/msdos/encyclopedia/section2/) · [DJGPP executable format](https://www.delorie.com/djgpp/doc/exe/)
- Verify interrupt selectors and hardware port meanings against the exact machine configuration. [Ralf Brown’s Interrupt List](https://www.cs.cmu.edu/~ralf/files.html) · [DOS handle read](https://fd.lod.bz/rbil/interrup/dos_kernel/213f.html) · [BIOS wait](https://fd.lod.bz/rbil/interrup/bios/1586.html) · [HelpPC port tables](https://stanislavs.org/helppc/ports.html)
- Identify a secondary executable before assigning DOS stub findings to gameplay. [Microsoft PE format](https://learn.microsoft.com/en-us/windows/win32/debug/pe-format) · [Open Watcom DOS/4GW programming guide](https://open-watcom.github.io/open-watcom-1.9/pguide.html)
- Verify native APIs against the current SDL documentation. [Logical presentation](https://wiki.libsdl.org/SDL3/SDL_SetRenderLogicalPresentation) · [Gamepad input](https://wiki.libsdl.org/SDL3/SDL_OpenGamepad) · [Audio streams](https://wiki.libsdl.org/SDL3/SDL_OpenAudioDeviceStream) · [Monotonic ticks](https://wiki.libsdl.org/SDL3/SDL_GetTicksNS)
- For the Ghidra importer’s treatment of the entry point, segment relocations and original file bytes, consult the implementation for the tested release. [Ghidra 11.4.2 MZ loader](https://github.com/NationalSecurityAgency/ghidra/blob/Ghidra_11.4.2_build/Ghidra/Features/Base/src/main/java/ghidra/app/util/opinion/MzLoader.java) · [Microsoft Press loader description](https://msarchive.pcjs.org/mspl13/msdos/encyclopedia/section2/)
- Ray Duncan’s DOS programming reference is also catalogued by the Internet Archive. [Advanced MS-DOS Programming, 1988](https://archive.org/details/advancedmsdospro0000dunc)
